# デバッグメモ

## Chrome DevTools と Visual Studio のキー対応

```ts
// Visual Studio（C#） → Chrome DevTools（Sources）
// F9        → Ctrl+B     選んだ行にブレークポイントを付ける・外す。
// F5        → F8         停止中の処理を再開する。次のブレークポイントで止まる。
// F10       → F10        呼び出した関数をまとめて実行し、次の行に進む。
// F11       → F11        呼び出した関数の中に入って処理を追う。
// Shift+F11 → Shift+F11  今いる関数の残りを実行して、呼び出し元に戻る。

// Chrome では F12 で DevTools を開いてから Sources を選ぶ。
```
